# Python Programming Lab — 3rd Sem CSE

Welcome! This repository contains reference materials and solutions for the 3rd-semester CSE Python Programming Laboratory course. 

As your Academic Associate (TA), I’ve set up this space to help you navigate your lab sessions, debug your code and understand the practical applications of what you're learning in your theory class.


## Repository Structure

```
ta-python-lab/
├── README.md               # Repository documentation and guide
├── assignments/            # Official lab PDFs and problem statements from faculty
├── references/             # Conceptual summaries, cheatsheets and guides for each lab
└── solutions/              # Reference implementations (Google Colab .ipynb notebooks)
```


## How to Use These Resources

1.  **Locate and try the assignments:** Problem statements will be uploaded here in the `assignments/` folder as well as to your official Google Classroom. Use these PDFs to understand the requirements and attempt the logic on your own first.
2.  **Review the solutions:** If you get stuck, want to check your logic or want to see an alternative approach, open the corresponding notebook in the `solutions/` folder.


## Quick Tips for the Lab

*   **Read the Comments:** The reference codes include inline comments explaining *why* certain logic or data structures were used.
*   **Don't just copy-paste:** Use these notebooks to understand the underlying logic. You will need to explain your code during your lab vivas/evaluations!
*   **Ask for help:** If you spot a bug in my solution or have a question about an approach, feel free to open an Issue here or reach out during lab hours.
